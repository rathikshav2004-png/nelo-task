# Task Manager (React + Tailwind CSS)

A simple task management application with login, task creation, editing, deletion, filters, and search functionality.

## Features
- Login system (local storage)
- Add / Edit / Delete tasks
- Mark tasks as completed
- Filter tasks by status (All / Completed / Pending)
- Fully responsive UI
- LocalStorage persistence

## Tech Stack
- React
- Vite
- Tailwind CSS
